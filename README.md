# jingyao-wei.github.io

Personal academic website of Jingyao Wei (PhD Candidate in Economics, NHH).

The site is live at https://jingyao-wei.github.io

## How this repository works

The root of this repository contains the **built website** (plain HTML/CSS),
served directly by GitHub Pages (Settings → Pages → Deploy from a branch →
`main` → `/ (root)`).

The `source/` folder contains the Hugo project the site is generated from.
To make changes, edit the files in `source/` (see `source/UPDATING.md`),
rebuild with Hugo, and replace the files at the root — or simply ask Claude
to make the change and upload the refreshed files.

Created following [GaryKing.org/mysite](https://garyking.org/mysite).
